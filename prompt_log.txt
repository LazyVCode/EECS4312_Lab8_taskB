## What the file must contain

Each entry in **`constraint_prompt_log.txt`** should include **three parts**:

1️⃣ **Prompt** – The exact question you asked the LLM
2️⃣ **Purpose** – Why you asked that prompt
3️⃣ **Response Summary** – A short summary (1–2 sentences) of the LLM response

The lab manual gives this required format: 

```
Prompt 1: [Prompt text]

Purpose: Why the prompt was asked 
(e.g., clarify persona need, check if a constraint is testable, brainstorm constraints)

Response summary:
Brief description of the LLM response (1–2 sentences)
```

---

```
Prompt 1: Based on the persona Jane, what system constraints could reduce notification overload?

Purpose: To brainstorm possible constraints derived from Jane’s need for minimal notifications.

```
Prompt 2: How can a system ensure deterministic behavior when multiple reminders occur at the same timestamp?
